# VidGrab MVP

A responsive video-downloader landing page/UI for content the user is authorized to download.

## Run locally
Open `index.html` in a browser, or use any static web server.

## Included
- Responsive homepage
- YouTube / Shorts / Instagram / Facebook URL detection
- Paste button
- Result/status card
- FAQ
- Ad placeholder
- Privacy/Terms/DMCA/Contact navigation placeholders
- Dark UI
- No framework required

## Production next step
Connect a backend that only handles permitted/authorized content and complies with the applicable platform terms, copyright law, and security requirements. Add authentication/rate limits, temporary processing, logging, abuse prevention, and automatic cleanup as needed.
